# Global Petrol Price Shock Analysis (2026 US–Iran Conflict)

This project analyzes the impact of the 2026 US–Iran conflict on global petrol prices using data science techniques.

## Objectives

- Analyze global petrol price increases
- Study oil price trends during geopolitical conflicts
- Examine economic impact across countries
- Forecast crude oil prices using time-series models

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly

## Key Insights

- Brent crude prices increased over 50% during the conflict
- Oil-import dependent countries experienced the highest petrol price increases
- Global oil supply disruption caused strong price volatility

Kaggle dataset:
